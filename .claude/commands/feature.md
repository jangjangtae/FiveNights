다음 기능을 역할별 서브 에이전트로 진행해 줘: $ARGUMENTS

순서:
1. **planner** 에이전트에게 작업 명세를 받는다. "사용자 확인 필요" 항목이 핵심 결정(장르, 루프, 목표, 아트 방향 등)이면 여기서 멈추고 나에게 묻는다. 사소한 것은 추천안으로 진행하고 그렇게 했다고 적는다.
2. **developer** 에이전트에게 명세를 넘겨 구현시킨다. 컴파일 에러 0개가 아니면 다음 단계로 가지 않는다.
3. **tester** 에이전트에게 명세의 완료 기준과 개발자 보고를 넘겨 확인시킨다. 실패가 있으면 버그 리포트를 developer에게 넘겨 고치고 다시 테스트한다 (최대 2번 반복, 그래도 안 되면 멈추고 보고).
4. **reviewer** 에이전트에게 변경 사항을 검토시킨다. `[필수]` 항목은 developer가 고치고 다시 검토한다.
5. 다 끝나면 `<영역>: <무엇을 했는지>` 형식으로 커밋하고 푸시한다 (CLAUDE.md Git 규칙).

마지막에 나에게 한 번에 정리해서 보고한다:
- 무엇을 만들었는지, 바뀐 파일
- 테스트 결과와 확인하지 못한 것
- 검토에서 남은 권장 사항
- 내가 직접 플레이해서 봐야 할 것
