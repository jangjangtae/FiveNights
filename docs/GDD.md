# 다섯 번의 밤: 게임 기획서 (요약)

> 가제. 숫자(시간, 목숨, 경계도 등)는 전부 플레이테스트로 조정할 초기값이다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 탑다운 2D 공포 잠입 |
| 엔진 | Unity 6.3 LTS (6000.3.29f1), URP 2D |
| 플랫폼 | 웹(WebGL), itch.io나 개인 페이지에 공개 (Steam 아님) |
| 개발 | 1인 개발 포트폴리오 (게임 AI 직군 + 일반 게임 개발자 지원용) |
| 핵심 | 밤마다 플레이어의 침입 패턴을 기억하고 대응을 바꾸는 경비 AI |

## 2. 스토리

플레이어는 비밀 군사 실험을 폭로하려는 탐사 기자다. 외딴 심야 연구소에 5일 밤 동안 숨어들어 야간 경비를 피해, 하룻밤에 하나씩 증거를 빼낸다.

| 밤 | 증거 |
|---|---|
| 1일차 | 출입 기록부 사진 |
| 2일차 | 실험 보고서 |
| 3일차 | 녹음 파일 |
| 4일차 | 실험실 내부 사진 |
| 5일차 | 핵심 서버 데이터 |

**반전 후보 (미확정):** 실험의 정체는 침입자를 학습하는 군사용 감시 AI였고, 경비들은 그 AI의 테스트였다.

## 3. 핵심 루프 (하룻밤)

1. **준비**: 평면도와 지난밤 경비 보고서를 보고 도구 2개를 고른다.
2. **침입**: 제한 시간(예: 5분) 안에 증거를 찾는다. 시야와 카메라를 피하고 발소리를 관리한다.
3. **탈출**: 증거를 들고 출구까지 빠져나간다.
4. **경비 보고서**: 경비가 이번 밤에 알아낸 것과 다음 밤에 바뀔 것을 보여준다.

## 4. 규칙

- 발각되면 경비가 추격한다.
- 잡히면 목숨 -1, 그날 밤 시작 위치로 돌아가 재시도한다. 잡힌 위치는 경비의 기억에 남는다.
- 목숨은 3개이고 밤마다 3개로 회복된다.
- 목숨을 다 잃으면 그날 밤은 실패로 처리하고 다음 밤으로 넘어간다. 경계도가 크게 오른다.
- 5일차에 마지막 증거를 빼내면 클리어.
- 점수: 발각 횟수, 걸린 시간, 획득한 증거.
- 경계도: 0~100, 밤을 거듭하며 누적된다.

## 5. 시스템

| 시스템 | 내용 |
|---|---|
| 플레이어 이동 | 걷기 / 웅크리기 / 달리기. 속도마다 발소리 반경이 다름 |
| 상호작용·도구 | 문 따기, 카메라로 증거 촬영(플래시를 쓰면 눈에 띔), 연막, 돌 던지기 |
| 감지 (Perception) | 시야 부채꼴 + 레이캐스트로 가림 판정, 소리 반경, 의심 게이지가 차면 발각 |
| 경비 행동 | 순찰 → 의심 → 수색 → 추격 → 복귀. 1차 구현은 유한 상태 기계 + 2D 경로 탐색(NavMeshPlus 또는 A*) |
| 기억 (Memory) | 밤마다 지나간 칸, 발각 위치, 사용한 통로를 격자 히트맵으로 누적 |
| 전략 (Strategy) | 히트맵을 보고 순찰 추가, 카메라 설치, 통로 잠금, 고정 배치 중에서 선택. 점수 규칙 + 경계도 예산 |
| 경비 보고서 UI | 밤이 끝날 때 경비가 알아낸 것과 다음 밤 변화를 표시 |

## 6. AI / 강화학습 원칙

- **게임 중에는 학습하지 않는다.** 미리 학습한 정책 하나를 쓰고, 침입 히트맵을 관측값으로 넣는다 (contextual policy).
- **전략은 규칙 기반으로 유지한다.** 나중에 수색·추적 행동만 ML-Agents로 학습한 RL 정책으로 교체해서, 규칙 기반 경비와 비교한다.
- 이를 위해 감지 → 판단 → 행동 사이의 인터페이스를 처음부터 분리해 둔다.

## 7. 아트 방향

- 단순한 도형 + URP 2D 라이트와 그림자. 손전등 빛, 깜빡이는 형광등, 비상등.
- 색의 역할:

| 색 | 역할 |
|---|---|
| 밤의 남색 | 배경 |
| 손전등 노랑 | 경비, 시야 |
| 발소리 청록 | 플레이어, 소리 |
| 경보 빨강 | 카메라, 발각 |
| 흔적 주황 | 침입 기록(히트맵) |

- 시야와 소리 범위는 항상 화면에서 읽혀야 한다.

## 8. 개발 단계

| 단계 | 내용 | 통과 기준 |
|---|---|---|
| 0. 프로토타입 | 방 하나, 플레이어 이동·웅크리기, 경비 1명(순찰·시야·추격), 웹 빌드 테스트, 모델 추론 테스트 | 들키고 도망치는 게 재미있는가 |
| 1. 수직 슬라이스 | 연구소 한 층, 경비 3명, 카메라, 소리 감지, 도구 2개, 증거 획득과 탈출 | 하룻밤을 처음부터 끝까지 완주 |
| 2. 적응하는 경비 | 히트맵, 규칙 대응 4종, 경계도, 경비 보고서, 5일 밤 루프 | 밤마다 경비가 달라지는 게 체감됨 |
| 3. 완성도·웹 공개 | 연출, 사운드, UI 정리, 최적화, itch.io 등에 공개 | 외부 사람이 끝까지 플레이 |
| 4. RL 경비 | ML-Agents로 수색·추적 정책 학습, 규칙 경비와 비교 모드, 영상 | 비교 결과를 포트폴리오로 정리 |

## 9. 1차 버전에서 제외

- 건물 여러 개
- 스토리 컷신
- 전투
- 온라인 기능
